# Code of conduct

Patchwise is a learning project. Participation should make security knowledge more accessible, not more intimidating.

## Expected behavior

- Be respectful, specific, and patient.
- Critique code and ideas without attacking people.
- Welcome contributors who are new to security or open source.
- Use safe, redacted examples.
- Give credit for ideas and work.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, deliberate publication of secrets, and attempts to pressure others into unsafe disclosure are not accepted.

## Enforcement

Report conduct concerns privately to the repository owner through the contact method on their GitHub profile. Maintainers may edit or remove content and temporarily or permanently restrict participation when necessary.
