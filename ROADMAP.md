# Roadmap

## Available now

- JavaScript and TypeScript scanning
- Nine deterministic security rules
- Plain-language explanations and safe attack ideas
- Re-scanned, verified automatic fixes
- Interactive lessons
- Scan and lesson APIs
- Input limits and rate limiting
- Public CI, dependency updates, and CodeQL configuration

## Next

- More rule fixtures and reduced false positives
- Accessible keyboard navigation and screen-reader testing
- Import and export of local scan reports
- Additional lessons for authentication and authorization
- Optional repository and pull-request scanning

## Later

- Python support
- Dependency vulnerability checks using an open advisory database
- Community rule packs
- Internationalized lessons

Paid AI services are not part of the required roadmap. Explanations remain deterministic so the core project is free to run and reproducible.
